# 研究维度参考

## 单曲研究维度

根据歌曲特点，从以下维度中**动态选择**最值得研究的方向：

| 维度 | 适用场景 |
|------|---------|
| 创作背景 | 有故事可讲（演唱会即兴、个人经历触发） |
| 艺人阶段 | 该歌曲在艺人职业生涯中的位置 |
| 制作过程 | 制作人、录音室、DAW、合成器、鼓机 |
| 编曲逻辑 | 和声进行、乐器编排、结构 |
| Groove/节奏 | 节奏设计、律动感、节奏密度 |
| 声音设计 | 合成器音色、texture、空间感 |
| 低频设计 | Bassline 设计、低频处理 |
| Stereo Image | 立体声场、空间感、混音宽度 |
| 人声处理 | 和声编排、人声效果链、真假音 |
| Mixing/Mastering | 混音理念、母带处理特点 |
| Sample 来源 | Sampled 了哪首歌、采样如何被改造 |
| 歌词分析 | 意象、修辞、与旋律的关系 |
| 市场表现 | 榜单成绩、流媒体数据、奖项 |
| 文化意义 | 对社会/流派的影响、时代背景 |

## 单曲必须确认的信息
- 歌曲名（准确名称）
- 原唱/主要艺人
- 作词人、作曲人
- 专辑名、发行日期
- 流派/曲风（最多 3 个）
- 语言

## 专辑研究维度
- 曲目列表与编排逻辑
- 制作人与制作背景
- 录音技术与制作特点
- 曲目间的关联与叙事
- 商业表现与评价
- 历史地位

## 专辑必须确认的信息
- 专辑名、主要艺人
- 发行日期、唱片公司
- 流派/曲风、曲目数量
- 制作人

## 歌手研究维度
- 音乐生涯关键节点
- 风格演变与转折点
- 代表作品分析
- 创作理念与艺术追求
- 行业影响与传承

## 歌手必须确认的信息
- 歌手名/艺名
- 出生地/国籍、出道年份
- 代表作品、主要流派
- 重要奖项
