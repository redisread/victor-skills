# Tool Share

调研工具信息，生成结构化分享文章。

## 核心流程

```
收集信息 → 调研 → 生成文章 → 确认输出方式
```

## Step 1: 收集工具信息

向用户确认（如未提供）：
- **工具名称**（必填）
- **工具类型**：CLI / 框架 / 库 / SaaS / IDE插件 / 其他
- **主要用途**：一句话描述
- **技术栈**：如 Java、Python、Node.js

## Step 2: 调研

使用 WebSearch 和 WebFetch 获取：
1. **官网与文档** — 官网、文档、GitHub 链接
2. **基本使用** — 安装方式、快速开始、核心 API
3. **最佳实践** — 社区推荐模式、常见陷阱、性能建议

## Step 3: 生成文章

按模板生成（详见 [references/article-template.md](references/article-template.md)）：
- 基本信息表 → 背景介绍 → 快速开始 → 核心功能 → 最佳实践 → 常见陷阱 → 适用场景 → 相关资源

## Step 4: 输出

询问用户保存方式：
1. 直接输出到终端
2. 保存为 `tool-share-{工具名}.md`
3. 发布到知识库

## 注意事项

- 链接必须是验证过的真实 URL，不编造
- 代码示例必须语法正确、可运行
- 最佳实践来自官方文档或社区共识，标注来源
- 文章语言中文，技术术语保持英文
- 信息有限时标注"信息截至调研日期"

## 验证

- [ ] 所有链接可访问
- [ ] 代码示例可运行
- [ ] 文章结构完整（8 个章节）
