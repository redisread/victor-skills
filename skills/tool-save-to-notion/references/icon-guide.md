# 图标选择指南

## 按类型默认图标

| 类型 | 默认图标 | 特殊情况 |
|------|---------|---------|
| 软件 | 💻 | AI工具🤖、设计🎨、开发🛠️ |
| 网站 | 🌐 | AI服务🤖、学习📚、云服务☁️ |
| 浏览器插件 | 🔌 | 生产力⚡、安全🔒、AI🤖 |
| Prompt | 📝 | 代码💻、创意✨、分析🔍 |
| 工具包 | 📦 | Python🐍、JS📜、AI/ML🧠 |

## 按特征优先级

1. 工具明确特征（Python 项目 → 🐍）
2. 功能领域（AI → 🤖，设计 → 🎨）
3. 类型默认图标
