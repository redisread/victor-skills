### 新增歌曲到「音乐」database 参考

**创建页面时必填属性**：
```bash
# POST /v1/pages
{
  "parent": {"database_id": "3550f06d1a7f800ea4adf722d176a2e0"},
  "properties": {
    "名称": {"title": [{"text": {"content": "歌曲名"}}]},
    "原唱": {"rich_text": [{"text": {"content": "歌手名"}}]},
    "🎼 作曲人": {"rich_text": [{"text": {"content": "作曲人"}}]},
    "🏷️ 作词人": {"rich_text": [{"text": {"content": "作词人"}}]},
    "📀 专辑": {"rich_text": [{"text": {"content": "专辑名"}}]},
    "📝 语言": {"select": {"name": "中文"}},
    "发行时间": {"date": {"start": "YYYY-MM-DD"}},
    "网易云链接": {"url": "https://music.163.com/song?id=SONG_ID"},
    "🎵 流派/曲风": {"multi_select": [{"name": "流行"}]}
  }
}
```

**网易云音乐链接获取**：
- 网易云链接 URL 格式：`https://music.163.com/song?id=SONG_ID`
- 可通过 `opencli netease` 或 `autocli search netease` 命令搜索获取歌曲 ID
- 也可在网易云音乐网页版搜索后复制链接

**页面内容块建议结构**：
1. **歌曲详解** (heading_1 + paragraph) - 概述介绍
2. **基本信息** (heading_2 + bulleted_list_item) - 演唱/词曲/专辑/曲风列表
3. **创作背景与故事** (heading_2 + paragraphs) - 创作灵感、背景故事
4. **完整歌词** (heading_2 + paragraphs) - 用 divider 分隔歌词段落
